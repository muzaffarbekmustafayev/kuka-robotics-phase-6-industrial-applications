### 🌐 Phase Description (Trilingual)

#### 🇺🇿 O'zbekcha:
Murakkab 3D choklar bo'ylab payvandlash/yelimlash traektoriyalari, konveyerga moslashuvchi (Conveyor Tracking) palletizatsiya va saralash.

#### 🇷🇺 Русский:
Траектории сварки/нанесения клея по сложным 3D-швам, паллетизация с синхронизацией по конвейеру (Conveyor Tracking).

#### 🇬🇧 English:
Continuous 3D welding and glueing trajectories, conveyor tracking synchronization, and industrial sorting cells.

---

### 📑 Lessons Curriculum / Darslar Mundarijasi / Содержание уроков

* [**24-trajectory-welding-and-glueing**: 3D Continuous Trajectory Programming: Welding & Dispensing](./24-trajectory-welding-and-glueing)
  * 🇺🇿 Payvandlash va yelimlash texnologik talablari. Doimiy chiziqli tezlikda murakkab fazoviy 3D choklar bo'ylab harakat.
  * 🇷🇺 Технологические требования к сварке и склеиванию. Движение с постоянной линейной скоростью по сложным 3D-траекториям.
  * 🇬🇧 Welding and dispensing requirements. Continuous path velocity maintenance and Frenet-Serret 3D space curve tracking.

* [**25-palletizing-and-sorting-system**: Palletizing & Conveyor Tracking Dynamic Sorting System](./25-palletizing-and-sorting-system)
  * 🇺🇿 Palletizatsiya va konveyer harakat tezligiga moslashuvchi (Conveyor Tracking) aqlli saralash tizimi. KRL va Python integratsiyasi.
  * 🇷🇺 Паллетизация и система умной сортировки с отслеживанием конвейера (Conveyor Tracking). Интеграция KRL и Python.
  * 🇬🇧 Smart palletizing patterns and conveyor tracking dynamic interception. Mixed KRL and Python automation system.
